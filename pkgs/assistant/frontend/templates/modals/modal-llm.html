Chọn nơi xử lý câu trả lời: cục bộ (riêng tư, không cần Internet) hoặc đám mây (nhanh, cần API key).
🗂️ Model cục bộ (GGUF)
✨ Gợi ý thiết lập
  • Máy 8GB RAM: dùng Qwen2.5-1.5B (Q4) — nhẹ và tiếng Việt tốt.
  • Có GPU NVIDIA: đặt -ngl = 99 để đẩy toàn bộ layer lên GPU; không có GPU thì để 0.
  • Temperature 0.7 cân bằng; giảm về 0.3–0.5 khi cần câu trả lời chính xác, ít sáng tạo.
  • Context 4096 đủ cho hội thoại thường; tăng lên nếu bạn dán tài liệu dài.
  • Đám mây (DeepSeek / OpenAI / Gemini) không cần tải model nhưng cần API key và Internet.
